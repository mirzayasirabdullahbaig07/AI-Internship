# Day 20 - Code review of the capstone PR using the Week 2 criteria

> **Honest note:** the handbook asks for a live review of a **peer's** PR. I have no peer PR, so this is a **practice review of the Day 19 capstone PR** by an AI reviewer (Claude), using the Week 2 review criteria and the Day 12 findings format. It is not a substitute for a human peer review on GitHub. The reviewer also wrote the code, so independence is limited: every claim below is backed by a probe, test or command, and two findings were already fixed.

**Reviewed:** `day-19-capstone-leave-request/` (21 non-evidence files, 955 lines of source). Method: review the **diff, not the author**; every suspicion was reproduced in a real browser or test before being reported.
